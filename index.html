一、我们如何收集和使用您的个人信息

（一）我们如何收集您的个人信息

在您使用《动物推币机》过程中，我们会按照如下方式收集您的个人信息：

1. 游戏服务与本地存档

当您使用游戏服务时，我们会在您的设备本地保存游戏进度、金币、成就等玩法数据（通过设备本地存储实现）。 收集上述信息是为了保障您正常使用服务、维护基础功能运行并提升游戏体验。 如您清除应用数据或卸载应用，相关本地存档可能无法恢复。

2. 广告与激励视频服务

当您主动观看激励视频广告以获取游戏内奖励时，我们会通过接入的第三方广告 SDK（TapADN / Dirichlet） 在必要范围内处理设备相关信息（如设备型号、操作系统版本、网络状态、IP 地址、广告标识符等，具体以该 SDK 隐私政策为准）， 用于广告投放、填充、反作弊及效果统计。如您拒绝相关授权或不观看广告，不影响您使用本应用的基本玩法，但可能无法获得对应广告奖励。

3. 保障网络和服务安全

为保障网络和游戏/广告服务的安全性与稳定性，我们或第三方 SDK 可能收集设备识别相关信息、网络状态、访问时间等， 用于排查故障、防范作弊与滥用。如您不提供上述信息，部分联网功能（如广告）可能无法正常使用。

4. 当前版本说明

当前《动物推币机》APK 版本以本地运行为主，不强制要求注册账号、不强制进行实名认证。 若后续版本新增登录、云存档、排行榜、分享等功能并因此需要收集更多信息，我们将更新本隐私政策并再次征得您的同意。

（三）我们如何使用您的个人信息

  • 我们会根据本政策的约定并为实现服务目的对所收集的个人信息进行使用。
  • 您在使用服务期间提供或产生的信息，除非您删除或通过系统设置拒绝收集，否则将在您使用服务期间持续授权我们使用；您停止使用或卸载应用后，我们将停止使用并按本政策处理相关信息。
  • 我们可能对服务使用情况进行统计，并可能与公众或第三方共享不包含身份识别信息的统计信息，用于产品开发、服务优化与安全保障。
  • 当我们要将您的个人信息用于本政策未载明的其他用途时，会事先以清晰方式征求您的同意。

（四）其他规则

根据相关法律法规及国家标准，以下情形中，我们可能会收集、使用您的相关个人信息而无需征求您的授权同意：

  • 与我们履行法律法规规定的义务相关的；
  • 与国家安全、国防安全直接相关的；
  • 与公共安全、公共卫生、重大公共利益直接相关的；
  • 与刑事侦查、起诉、审判和判决执行等直接相关的；
  • 出于维护个人信息主体或其他个人的生命、财产等重大合法权益但又很难得到本人授权同意的；
  • 所涉及的个人信息是个人信息主体或监护人自行向社会公众公开的；
  • 根据个人信息主体要求签订和履行合同所必需的；
  • 从合法公开披露的信息中收集个人信息的，如合法的新闻报道、政府信息公开等渠道；
  • 维护所提供产品或服务的安全稳定运行所必需的，如发现、处置产品或服务的故障。

二、我们如何保存您的个人信息

我们将在本政策载明的目的所需及法律法规要求的最短保存期限之内，保存您的个人信息。 前述期限届满后，我们将对您的个人信息做删除或匿名化处理。

我们在中国境内运营过程中收集和产生的个人信息将保存在中国境内 （为本隐私政策之目的，“中国境内”不含中国港澳台地区），以下情形除外：

  • 法律有明确规定；
  • 获得您的明确授权；
  • 您要求获取境外服务等个人主动行为。

针对以上情形，我们会确保依据本隐私政策以及相关法律规定对您的个人信息提供足够的保护。

说明：当前版本的游戏进度等玩法数据主要保存在您的设备本地；广告相关数据处理以其 SDK 运营方说明为准。

第三方合作伙伴通过 Cookies 或同类技术收集和使用您的信息，不受本政策约束，而受其自身信息保护声明约束。 您可在系统或浏览器设置中管理相关权限；若您拒绝，可能影响部分功能（如广告）的正常使用。

  • 事先获得您明确的同意或授权；

（四）公开披露

除非另有约定或法律明确规定，我们不会公开披露您的个人信息。

（二）删除您的个人信息

在以下情形中，您可以通过本政策载明的方式向我们提出删除个人信息的请求：

  • 我们违反法律、行政法规或与您的约定收集、使用个人信息；

本政策所指的重大变更包括但不限于：

  • 我们的服务模式发生重大变化；

  • 您参与个人信息处理方面的权利及其行使方式发生重大变化；
  • 我们的联系方式及投诉渠道发生变化；
  • 个人信息安全影响评估报告表明存在高风险时。
